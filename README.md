# Meridian

A living atlas: a full-viewport rotating 3D globe with glowing location markers, drag-to-spin, and click-to-focus.

## Run

```bash
npm install
npm run dev
```

Then open the app at the URL Vite prints (port 8080).

- Drag the globe to spin. Auto-rotate pauses while you interact.
- Click a light, or a name in Featured, to fly there.
- Arrow keys cycle places. Escape clears the focus.

## Stack

React, TanStack Start, Three.js, React Three Fiber.
